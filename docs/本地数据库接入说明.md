## 配置与启动

连接信息和持久使用的随机 JWT 签名密钥已保存到 `scaffold-system/.env`。该文件被 Git 忽略，文档不记录真实密码。模板为同目录 `.env.example`。

在项目根目录的 PowerShell 终端执行：

```powershell
# 只检查配置格式
.\scaffold-system\Start-Local.ps1 -ValidateOnly

# 编译后启动；先停止已有8080后端，避免端口冲突
.\scaffold-system\Start-Local.ps1 -Build

# 已有最新构建时直接启动
.\scaffold-system\Start-Local.ps1
```

脚本只解析每行 `变量名=值`，可用成对单引号或双引号包裹值，不执行命令或变量展开。`-Build` 跳过集成测试，避免将测试夹具写入真实开发库。完整测试请继续使用独立测试库。

如果直接从 IDE 启动，需要将 `.env` 中的变量导入 IDE 的运行环境；Java 本身不会自动加载该文件。后端停止后可在上述终端重启。当前前端开发进程继续使用原来的5173端口。

首次登录账号为 `admin`，初始化开发密码为 `admin123`，按页面图片填写验证码。
