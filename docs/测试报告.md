## 回归范围

- 直接编辑自身角色、越权创建超级管理员、修改高权限用户、跨部门编辑/停用/重置密码/删除均被拒绝；合法同部门编辑和角色授予成功。
- 无授权的安全结构写权限不向前端返回；超级管理员自身不能停用或移除超级管理员角色。
- 缺少密码、非法状态、无效关联编号被拒绝，失败请求不会写入用户记录。
- 验证码响应不包含答案字段，PNG 可正确解码，并发消费同一验证码仅一个请求成功。
- 账号连续密码失败后返回429，改变账号大小写不能绕过计数。
- 自助改密、后台重置、停用、重新启用和删除后旧会话均无法访问用户接口及工作台；两个旧登录会话同时失效。
- 多角色、多岗位完整返回；真实编辑表单回显两个角色、两个岗位，修改昵称后数据库仍保留全部关联，部门编号一致。
- 部门不能挂到自身或后代；合法移动后孙级部门的祖先路径同步更新。
- 旧菜单响应、旧401、慢退出请求不会污染新登录态；低权限页面、按钮和无菜单账号落点保持正确。
- 自助改密后立即跳回登录页，新密码可以重新登录。
- 前后端导出工具保留转义规则，并把公式前缀当作普通文本导出。
- 已分配的停用岗位可保留；不能新增停用岗位关联。

## 复现命令

先按[环境说明](环境说明.md)设置数据库、Redis、JWT 环境变量，并在独立测试库按顺序导入 V1、V2、V3。测试会写入夹具和日志，部分原有日志测试会清理日志表，因此应使用独立测试库。

在 `scaffold-system` 目录执行：

```powershell
mvn test
mvn package
```

不连接外部服务时，可执行系统层及其依赖的单元测试：

```powershell
mvn -pl scaffold-system -am test
```

在 `scaffold-vue` 目录执行：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
npm run lint
npm test
npm run build
npm audit --registry=https://registry.npmjs.org
```

浏览器回归需要运行前后端，并安装 Python Playwright 与 Chromium；在前端目录执行，端口替换为独立测试 Redis 实例的实际端口：

```powershell
$env:SCAFFOLD_TEST_REDIS_PORT = '16386'
python scripts/session-regression.py --base-url http://127.0.0.1:15186
```

脚本直接从本机独立测试 Redis 读取验证码答案，不向应用加入验证码绕过接口。它会清理自己创建的用户、角色；截图生成于项目 `.tmp-verification` 目录。集成测试资源只提高测试进程的 IP 频率限额；密码失败锁定仍启用。重复运行浏览器测试时若触及频率限制，应等待窗口恢复，或仅对独立测试应用提高限额。
