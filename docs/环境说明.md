## 端口与环境变量

日常开发默认使用后端 8080、前端 5173、MySQL 3306、Redis 6379。本次验证另外启动了 MySQL 13316、Redis 16386，并使用后端 18086、前端 15186；集成测试由 Spring Boot 分配随机 HTTP 端口。临时实例仅监听回环地址，没有修改已有服务或业务数据库。

Java 后端读取进程环境变量，不会自行加载 `.env`。Windows 可使用 `scaffold-system/Start-Local.ps1` 加载同目录 `.env`，或通过 IDE 运行配置设置环境变量。仓库已忽略真实 `.env`，仅提交空密码的 `.env.example` 模板。

已按用户要求接入本机 MySQL `127.0.0.1:3306/scaffold_system` 和 Redis `127.0.0.1:6379` 的15号逻辑库。真实连接配置保存在 `scaffold-system/.env`，完整记录见[本地数据库接入说明](本地数据库接入说明.md)。上文独立端口为上一轮隔离测试环境。

| 环境变量 | 中文说明 |
| --- | --- |
| `JWT_SECRET` | 必填，至少32字节的随机签名密钥；不提交到仓库 |
| `DB_HOST`、`DB_PORT`、`DB_NAME` | 数据库地址、端口、库名 |
| `DB_USERNAME`、`DB_PASSWORD` | 实际数据库账号和密码 |
| `DB_TIMEZONE` | 数据库会话时区，默认 `+08:00` |
| `REDIS_HOST`、`REDIS_PORT`、`REDIS_PASSWORD` | Redis 地址、端口、密码 |
| `REDIS_DATABASE` | Redis 逻辑库编号，默认0；本机配置为15 |
| `SERVER_PORT` | 后端 HTTP 端口，默认8080 |
| `VITE_API_PROXY_TARGET` | 前端开发代理目标，默认 `http://localhost:8080` |
| `SCAFFOLD_TEST_PASSWORD` | 浏览器回归使用的测试管理员密码 |
| `SCAFFOLD_TEST_REDIS_PORT` | 浏览器回归专用的回环 Redis 端口，必须显式提供 |
| `SCAFFOLD_TEST_REDIS_PASSWORD`、`SCAFFOLD_TEST_REDIS_DATABASE` | 浏览器测试 Redis 密码和数据库编号 |

PowerShell 可为当前终端生成临时签名密钥：

```powershell
$env:JWT_SECRET = [guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
```
